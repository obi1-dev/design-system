# obi1.dev

obi1 のデザインシステム。技術ブログ obi1.dev、スライド、ポートフォリオで共有する。

- **骨格は「静かな編集室」**——白い紙に墨の文字、細い罫線、余白と整列。装飾ではなく、文章と制作物で書き手を伝える。
- **ブランドは「冬空と稜線」**——八ヶ岳のふもとの暮らしから取った色と形。主役は冬の空の青、脇役は森の緑、地は雪、差し色は朝焼け。モチーフは八ヶ岳連峰の稜線と蓼科山。スタイリッシュさと自然が同居する印象を目指す。

このシステムは `obi1-dev/obi1.dev`（main@5f7e0d4）の `src/assets/globals.css`、`DESIGN.md`、各 Astro コンポーネントから抽出した。値はコードそのまま。

## 原則

1. **素朴さは余白・整列・少ない色で出す。** 薄い文字や小さすぎる文字で階層を作らない。補助文字の下限は 13px、色は `muted`（白地で 5.6:1）。
2. **文字の強弱で探させる。** 一覧はサムネイルを使わず、日付・タイトル・タグを列で揃える。タイトルだけが 600 の `ink`、ほかは等幅の小さな文字。
3. **区切りは罫線。影は使わない。** 区切りは `line` の 1px。ページ内の大きな区切り（セクション見出し）だけ `ink` の罫線にする。
4. **長文を無理なく読める。** 本文 17px（SP 16px）・行高 1.95・幅 720px。日本語の字間は広げない。

避けるもの: 強い影、グラデーション、巨大な宣伝文句、派手なサムネイル、低コントラストの本文。

## 色

ライト専用（ダークモードは廃止済み）。色はすべて、八ヶ岳のふもとで撮った写真から取った。

**ブランドの色**

| トークン | 値 | 名前 | 役割 |
| --- | --- | --- | --- |
| `accent` | #24538f | 冬空 | 主役。リンク・技術タグ・フォーカス・スライドの全面・OG 画像の地 |
| `accent-deep` | #1d4577 | 深い冬空 | 冬空の上に置く蓼科山のシルエット |
| `accent-faint` | #86a3c9 | 淡い冬空 | 冬空の上の等高線（装飾専用） |
| `forest` | #34503f | 森 | 脇役。夏や森の話題、図の 2 系統目 |
| `snow` | #eef2f6 | 雪 | スライドの額縁、冬空の上の補助の文字 |
| `sunrise` | #a85f3f | 朝焼け | 差し色。強調は 1 画面に 1 か所まで |

**骨格の色**

| トークン | 値 | 役割 |
| --- | --- | --- |
| `paper` | #ffffff | 地。ページ・カードとも白 |
| `ink` | #222322 | 本文・見出し・セクション罫線 |
| `muted` | #646965 | 日付・肩書き・目次・フッター |
| `line` | #d8dcda | 1px の区切り罫線・カード枠 |
| `surface` | #f5f6f6 | 表見出し・details の summary |

- **冬空の地**: スライドの表紙・章扉・締め、OG 画像は `accent` の全面に白文字（7.8:1）。補助の文字は `snow`（6.9:1）。`accent-faint` は 3.0:1 なので文字に使わない。
- **森と冬空**: 明るさが近い（1.2:1）。並べて区別させるときは、色だけでなく線の有無や文字でも区別する。

- **リンク**: `accent`（冬空）、下線 1px・オフセット 0.24em。hover で `ink` に戻る（150ms）。本文リンクは常に下線、ナビや記事タイトルは hover で下線を出す。色だけでリンクを示さない。
- **フォーカス**: `:focus-visible` に `accent` の 2px アウトライン、オフセット 5px。
- **コード・callout**: `code-*`、`callout-*` の淡い色はそれぞれの部品専用。他の用途に流用しない。
- **注意**: `line`（1.4:1）は装飾罫線専用。SP 目次の枠 `line-strong`（2.2:1）は操作部品の境界として 3:1 に届かない。ソースのまま記録し、改善候補とする。

## タイポグラフィ

| ファミリー | スタック | 用途 |
| --- | --- | --- |
| `sans` | Inter, Noto Sans JP | 本文・見出し・UI すべて（欧文は Inter、和文は Noto Sans JP） |
| `mono` | JetBrains Mono | 日付・タグ・セクション見出し・コード |

Google Fonts から Inter 400/500/600/700、Noto Sans JP 400/500/600/700、JetBrains Mono 400/500 を `display=swap` で読み込む。フォントが遅くてもフォールバックで本文を読めるようにする。`font-synthesis: none`。

- 見出しは 600–700、本文 400。大きい見出しほど字間をわずかに詰める（-0.025〜-0.055em）。
- 等幅は「情報のラベル」に使う。日付は `YYYY.MM.DD`、セクション見出しは英語（Articles / Profile）。
- 主なサイズ: 記事タイトル 38 → 本文 h2 25 → h3 21 → 記事行 19 → 本文 17 → 紹介文 15 → UI 14 → 補助 13。

## 余白・角丸・レイアウト

- **余白**は 8px 基準。よく使うのは 16 / 24 / 32 / 48 / 64、セクション間は 80 / 96。実装には 4・12・20・28 も現れる（`space-*` トークン参照）。
- **角丸**は 0–4px。罫線・ヘッダー・記事行は角を立て、箱（カード・コード・callout）だけ `radius-md`（4px）。インラインコードと画像は 3px。
- **影**は使わない（トークンも定義しない）。
- **幅**: ページ `page-width` 1080px（左右余白 40px、SP は 20px）。記事本文 `reading-width` 720px、その右に sticky 目次（最小 180px、間 64px）。
- **ブレークポイント**: 1023px 以下で目次を本文前の折りたたみに、記事行を 2 列に。767px 以下でメニューを折りたたみ、すべて一列。ヒーローは PC 中央揃え、SP 左揃え。
- 操作領域は 44px（`hit-target`）以上。hover に依存しない。

## 動き

使う動きは 3 つだけ。spring、大きな移動、パララックス、常時ループは使わない。

- **自己紹介の登場**: 表示時に一度、opacity 0→1・translateY 6px→0、300ms ease-out。
- **リンクの状態変化**: 色と下線色、150ms。
- **メニュー・目次の開閉**: 約 200ms。

`prefers-reduced-motion: reduce` では登場と補間を止め、内容を即座に出す。JS やアニメーションが動かなくても本文を隠さない。

## 山のモチーフ

八ヶ岳のふもとから見える山の形を、ブランドの模様として使う（Mountains グループ）。写真から稜線を抜き出し、細かい凹凸をならして要所だけを曲線でつないだもの。形は変えず、高さだけを強調している。

- **八ヶ岳連峰の稜線**（`yatsugatake.svg`）: 基本のモチーフ。スライドの表紙の下端に、白い稜線と `accent-faint` の等高線 2 本で描く。
- **蓼科山のシルエット**（`tateshina.svg`）: インパクト用。スライドの章扉と締め、OG 画像の右下に、`accent-deep` の塗りと白い稜線で大きく置く。
- どちらも 1280×720 の座標で、`id` つきの path（`ridge`・`contour-1`・`contour-2`／`shape`・`ridge`）を持つ。配布パッケージは `@obi1-dev/design-system/motifs` でパスのデータを、`motifs/*.svg` で色を付けた SVG を出す。
- 使うのは冬空の地の上だけ。白い板の上や本文の中には置かない。文字とは重ねない。
- 山の形から住んでいる地域が推測できる。公開する場所では、その前提で使う。

## 画像とアイコン

- **ロゴ**はない。サイト名は文字（`brand` スタイル、Inter 700・字間 -0.055em）で示す。
- **プロフィール画像**はペンギンのイラスト（Profile グループ）。72px 角、白地・`line` 枠・4px 角丸、全身を切らない。トップと執筆者カードで同じものを使う。
- **ファビコン**は同じ画像から生成（Logos グループ）。元画像の赤い差し色はアイコンでのみそのまま使い、UI の色には持ち込まない。
- **アイコン**は原則使わない。矢印は文字（外部リンク `↗`、内部 `→`、戻る `←`）、メニューは 1.5px 線の 3 本線 SVG（`currentColor`）。callout だけ ℹ️ / ⚠️ を使う。
- 写真・イラストは必須にしない。
- **OG 画像**（OG グループ）: 1200×630、`accent`（冬空）の全面に白文字、右下に蓼科山のシルエット。左上にサイト名、タイトルは左揃え、左下に日付とタグ（`snow`）。角丸・影・グラデーションなし。Noto Sans JP 400/700。

## 文章のトーン

- 短く自然な日本語。「記事」「プロフィール」「つくったもの」「この記事を書いた人」など具体的なラベル。
- 誇張した肩書き・実績・架空の制作物を使わない。空のときは簡潔な空状態（`muted`）を出す。
- 外部リンクには `↗` と「（新しいタブで開く）」のスクリーンリーダー用テキストを必ず添える。

## アクセシビリティ

目標は WCAG 2.2 AA。本文 4.5:1 以上、UI 境界・フォーカス 3:1 以上。見出しの順序を守り、メニュー・目次はキーボードで開閉でき、状態を `aria-expanded` / `details` で伝える。スキップリンク（「本文へ」）を置く。

## コンポーネント

ナビゲーション（Header / Footer）、レイアウト（SectionHeading）、記事（ArticleRow / ArticleHeading / TableOfContents / AuthorCard）、本文 Markdown（CodeBlock / Callout / LinkCard / Details）。各カードは `components/bundle.css`（`globals.css` から抽出した実際の CSS）でスタイルした静的なプレビューで、元は Astro コンポーネントと remark プラグイン。

発表資料は Marp テーマ `obi1`（Marp グループ）で作る。雪の額縁に白い板、表紙・章扉・締めは冬空の全面。型と使い方は「スライド（Marp）」節、書き出した見本は Slides カード。

## 同期していないもの

- コンポーネントは Astro（`.astro`）と remark プラグインのため、JS バンドルは作っていない。プレビューは `bundle.css` による静的な再現。
- トップのヒーロー（`.introduction`）とプロフィール欄（`.about-grid` / `.profile` / `.project-entry` / `.profile-facts`）はカード化していない（CSS は `bundle.css` に含む）。
- フォントは Google Fonts 配信のため、ファイルは持たない。
- コードハイライトの色（Shiki `github-light`）はトークン化していない。
- `design/mockups/` の比較案 A / C は採用外のため含めない。
