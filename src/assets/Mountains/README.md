# Mountains

ブランドのモチーフ。八ヶ岳のふもとから見える山の形を、写真から抜き出してなめらかにし、山肌（塗り・雪・陰）を描いたもの。使い方はブランドブックの「山のモチーフ」節を参照。

- `yatsugatake.svg` — 八ヶ岳連峰。path `shape`（山の塗り）、`snow`（峰の雪）、`ridge`（稜線）、`contour-1`・`contour-2`（等高線）。スライドの表紙の下端に使う。
- `tateshina.svg` — 蓼科山。path `shape`（山の塗り）、`shade`（右の斜面の陰）、`snow`（雪の冠）、`ridge`（稜線）。スライドの章扉・締め、OG 画像に使う。

どちらも 1280×720 の座標。ファイルの色は確認用。実際は冬空の地の上で、`shape` を `accent-deep`、`snow` を `snow`、`shade` を `ink` の 22%、`ridge` を `paper`、等高線を `accent-faint` にする（配布パッケージの `motifs/*.svg` と `motifSvgs` はこの色づけ済み）。
