# Mountains

ブランドのモチーフ。八ヶ岳のふもとから見える山の形を、写真から抜き出してなめらかにしたもの。使い方はブランドブックの「山のモチーフ」節を参照。

- `yatsugatake.svg` — 八ヶ岳連峰の稜線。path `ridge`（稜線）、`contour-1`・`contour-2`（下に重ねる等高線）。スライドの表紙の下端に使う。
- `tateshina.svg` — 蓼科山のシルエット。path `shape`（塗り）、`ridge`（稜線）。スライドの章扉・締め、OG 画像に使う。

どちらも 1280×720 の座標。ファイルの色は確認用の冬空（#24538f）。実際に使うときは `accent-deep` で塗り、稜線を `paper`、等高線を `accent-faint` にする（配布パッケージの `motifs/*.svg` はこの色づけ済み）。
