# Marp

スライド用のテーマとテンプレート。使い方はブランドブックの「スライド（Marp）」節を参照。

- `obi1.css` — Marp テーマ（`@theme obi1`）。トークンの値を `:root` に持ち、山のモチーフを背景として埋め込んでいる（配布版はビルド時にトークンとモチーフから作り直す）。
- `template.md` — 12 枚のサンプル（表紙・目次・章扉・用語・コード・図と数字・2 カラム・表・記事行・引用・キーワード・締め）。HTML 有効で書き出す。
- `slide-01.png` 〜 `slide-12.png` — `template.md` を Marp CLI 4.1.2 で書き出した実際の画面（1280×720）。
