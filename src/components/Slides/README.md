# Slides

Marp テーマ `obi1` で作る発表資料。サイトと同じ白地・墨・青灰・細い罫線で、スライドの型を 6 つ（title / 本文 / chapter / split / center / end）持つ。

- 利用側が用意するもの: `assets/Marp/obi1.css`、`assets/Marp/template.md`、締めに使う `obi1-profile.png`。
- 書き出しは `--html --theme-set obi1.css`。詳しくはブランドブックの「スライド（Marp）」節。
- プレビューは `template.md` を実際に書き出した画面。
